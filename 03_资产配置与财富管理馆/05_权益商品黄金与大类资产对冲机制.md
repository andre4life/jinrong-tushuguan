# 05 权益商品黄金与大类资产对冲机制

## 1. 全球大类资产相关性矩阵与对冲本质

资产配置的最高境界是找到**“在不同经济环境和地缘周期中相互对冲、东方不亮西方亮”**的资产组合。

| 大类资产 | 核心抗性 / 顺风环境 | 弱势 / 逆风环境 | 与股票相关性 |
| :--- | :--- | :--- | :--- |
| **权益类（股票/指数）** | 经济复苏、企业盈利增长、流动性充裕 | 经济萧条、地缘危机、恶性滞胀 | 基准 (1.0) |
| **利率债（国债/国开债）** | 经济衰退、持续降息、资产负债表出清 | 经济过热、恶性通胀、加息周期 | **显著负相关 (-0.3 至 -0.6)** |
| **黄金 (Gold)** | **实际利率下行、地缘动荡、法币信用稀释** | 实际利率飙升、美元强势升值 | **低相关 / 负相关** |
| **大宗商品（原油/有色）** | 经济过热、全球通胀爆发、供给短缺 | 需求崩溃、全球深度衰退 | 低相关 / 顺周期 |

## 2. 黄金（Gold）在现代投资组合中的核心定位

黄金不是生息资产（不产生股息利息），但它是**人类五千年文明沉淀的终极货币与信用锚**。

### 黄金的定价公式
$$\text{黄金价格驱动力} \propto \frac{1}{\text{美国10年期国债实际收益率}} + \text{去美元化溢价} + \text{避险溢价}$$

- **配置比例建议**：在家庭整体投资组合中，配置 **5% - 10% 的黄金资产**（如黄金ETF 518880），能显著降低组合最大回撤。

# 01 现代资产配置理论与马科维茨有效前沿

## 1. 诺奖成果：现代投资组合理论 (MPT)

1952年，经济学家哈里·马科维茨（Harry Markowitz）发表了奠定现代金融学基石的论文《资产组合选择》，首次用数学严密证明了：**“分散投资是金融学中唯一的免费午餐 (The Only Free Lunch)”**。

### 核心数学逻辑
资产组合的预期收益率是各资产收益率的加权平均：
$$E(R_p) = \sum_{i=1}^n w_i E(R_i)$$

但资产组合的整体方差（风险 $\sigma_p^2$）不仅取决于单个资产的波动，更取决于**资产之间的相关系数 $\rho_{ij}$**：
$$\sigma_p^2 = \sum_{i=1}^n w_i^2 \sigma_i^2 + 2 \sum_{i=1}^{n-1} \sum_{j=i+1}^n w_i w_j \sigma_i \sigma_j \rho_{ij}$$

- 当两类资产**完全负相关 ($\rho = -1$)** 时，可以在不牺牲收益的前提下，将整体波动风险对冲至零。
- 当两类资产**低相关 ($\rho < 0.3$)** 时，组合的夏普比率（风险调整后收益）将大幅超越任何单一资产。

## 2. 有效前沿 (Efficient Frontier) 与资本资产定价模型 (CAPM)

```
预期收益率 E(R)
      ▲
      │           ┌───────────【有效前沿曲线 (Optimal Portfolios)】
      │          ╱
      │         ╱  ● 最高夏普比率组合 (Tangency Portfolio)
      │        ╱
      │       ● 最小方差组合 (Global Minimum Variance)
      │      (
      │     (   ◄── 无效组合区域（同等风险下收益更低，或同等收益下风险更大）
      │    (
      └────┴──────────────────────────────────────► 风险 / 波动率 (σ)
```

- **有效前沿**：在给定风险水平下能提供最高期望收益，或在给定期望收益下承担最小风险的资产组合边界。
- **夏普比率 (Sharpe Ratio)**：
  $$\text{Sharpe Ratio} = \frac{E(R_p) - R_f}{\sigma_p}$$
  代表每承担一单位波动风险，所换取的超额收益。

## 3. 家庭资产配置中的实践启示

1. ❌ **假分散**：买了5只不同基金经理的白酒或新能源股票基金（相关系数 $\rho > 0.9$，一跌全跌）。
2. ✅ **真分散**：跨资产类别（股票指数 + 确定性年金 + 国债 + 黄金）、跨地域（A股沪深300 + 美股标普500），真正实现低相关对冲。

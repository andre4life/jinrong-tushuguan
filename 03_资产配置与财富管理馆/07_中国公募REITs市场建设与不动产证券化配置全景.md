# 07 中国公募REITs市场建设与不动产证券化配置全景

> **导言**：深度精粹《中国REITs市场建设》及中国证监会/发改委基础设施公募 REITs 试点指引。公募 REITs（Real Estate Investment Trusts，不动产投资信托基金）是中国金融市场打通“重资产沉淀 ➔ 盘活存量 ➔ 证券化流动性”的里程碑式金融工具。系统拆解“公募基金 + ABS”双层结构、90% 利润强制现金分红机制、产权类 vs 特许经营权类 REITs 差异，以及在家庭资产配置中作为**“抗通胀、低波动、高现金分红”**的大类资产底仓价值。

## 一、中国公募 REITs 核心特征与投资价值

| 核心维度 | 中国公募 REITs 标准运作要求 | 对比股票 (A股/港股) | 对比传统住宅不动产 |
| :--- | :--- | :--- | :--- |
| **底层底层资产** | 交通基础设施、能源电力、生态环保、仓储物流、园区基础设施、保障性租赁住房、消费基础设施等。 | 上市公司整体经营与商业模式，受宏观与行业竞争剧烈波动。 | 单套住宅或商铺，流动性极差，租金收益率低（普遍 < 2%）。 |
| **强制分红要求** | **法律规定收益分配比例不得低于基金年度可供分配金额的 90%**！且每年不得少于 1 次。 | 无强制分红要求，分红比例由股东大会自由决定。 | 租金收取存在空置期与欠租风险，维护成本高。 |
| **收益风险特征** | **“中等风险、中等收益、稳定分红、抗通胀”**（介于股票与债券之间）。 | 高风险、高波动、追求资本利得。 | 重资产流动性冻结、可能沦为“负动产”。 |
| **交易流动性** | 在交易所（上交所/深交所）像买卖股票一样公开撮合交易，T+1 极速变现。 | 场内高流动性。 | 挂牌交易周期长达数月甚至数年。 |

## 二、产权类 REITs vs 特许经营权类 REITs 深度对比

```
【公募 REITs 两大核心分类判别】

  1. 🏢【产权类 REITs】(保租房/产业园/仓储物流/商业百货)：
     • 资产属性：拥有土地使用权及地上建筑物所有权；
     • 估值逻辑：每年租金分红 + 到期土地与房产资本增值潜力；
     • 期限特征：土地使用权期限较长（如 40-50 年），具备永续性运营价值。

  2. 🛣️【特许经营权类 REITs】(高速公路/光伏风电/污水垃圾处理)：
     • 资产属性：拥有特定年限内的特许收费权，无最终土地所有权；
     • 估值逻辑：类似“高息分期还本付息的固定收益”，内部收益率 (IRR) 清晰透明；
     • 期限特征：特许经营期届满后资产无偿移交政府，基金净值随时间推移逐渐归零（分红中包含本金返还）。
```

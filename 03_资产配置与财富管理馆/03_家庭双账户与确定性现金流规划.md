## 2. 为什么人生下半场“确定性现金流”远重于“资产账面净值”？

很多中产和高净值客户陷入一个巨大误区：**只看自己名下有多少套房子、股票账户有多少市值，却忽视了现金流的断裂风险**。

### 账面市值 vs 确定现金流深度对照

| 维度 | 账面资产（如房产 / 股票） | 确定性现金流（如年金险 / 终身现金流） |
| :--- | :--- | :--- |
| **可支配性** | 账面数字，变现需要寻找买家、撮合成交，受市场行情制约 | **每月/每年自动打到银行卡，活多久领多久，雷打不动** |
| **心理压力** | 价格暴跌时焦虑恐慌，不敢卖在低谷，陷入资金链断裂 | **与资本市场涨跌完全脱钩，不操心不焦虑，极致从容** |
| **长寿对冲** | 活得太久可能把本金花光，晚年陷入窘境 | **人活着就一直有钱领，彻底对冲“人活着钱没了”的终极风险** |

## 3. 退休养老金缺口测算模型

测算未来退休所需资金缺口的标准公式：
$$\text{养老金总需求} = \text{退休后每年期望支出} \times (1 + \text{通胀率})^{\text{距离退休年数}} \times \text{退休后生存年数}$$

$$\text{商业养老金缺口} = \text{养老金总需求} - (\text{社保基本养老金预期发放总额} + \text{其他确定性租金收益})$$

- **社保替代率现状**：目前我国城镇职工社保养老金平均替代率已降至约 40%-45%，仅靠社保只能维持最基础温饱。
- **刚需解法**：通过商业养老年金险提前锁定终身不缩水的高品质养老现金流。

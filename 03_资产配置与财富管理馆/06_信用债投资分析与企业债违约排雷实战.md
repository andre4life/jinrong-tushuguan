## 一、信用利差的底层数学模型与周期含义

$$	ext{信用债收益率} (Yield) = 	ext{无风险基准利率} (R_f) + 	ext{信用风险溢价} (	ext{Credit Spread}) + 	ext{流动性溢价} (	ext{Liquidity Premium})$$

* **当经济繁荣、流动性宽松时**：企业违约率低，信用利差被极度压缩（机构“下沉资质”博取高收益）；
* **当经济下行、信用收缩时**：弱资质民企与城投债信用利差急剧拉大，信用风险暴露，低评级债券遭遇流动性枯竭与抛售踩踏。

## 二、高净值客户非标固收“三大爆雷陷阱”与安全替代

| 传统非标高息理财（高危） | 爆雷底层逻辑与惨痛教训 | 终身养老年金 / 家族信托（安全替代） |
| :--- | :--- | :--- |
| **房地产信托资金池 (8%-10%)** | 底层项目烂尾、房企资金链断裂，信托公司打破刚兑，本金亏损超 70% 甚至血本无归。 | 🚀 **国家法定准备金兜底**：受《保险法》第92条保护，合同收益刚性保证，终身按月给付。 |
| **地方伪金交所定融产品** | 无实质资产抵押，涉嫌非法集资与影子银行，监管严厉清退取缔。 | 🛡️ **持牌金融机构正规受托**：信托公司 1000 万家族信托，财产独立于受托人破产清算。 |
| **民间借贷与企业高息集资** | 纯靠老板个人信用，一旦企业经营恶化直接跑路，名下资产全被银行抵押查封。 | 💎 **法商隔离防火墙**：在企业晴天剥离利润，锁定不可撤销人寿保单与信托现金流。 |

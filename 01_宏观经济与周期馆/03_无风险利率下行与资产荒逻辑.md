# 03 无风险利率下行与资产荒逻辑

## 1. 10年期国债收益率的标杆意义与破2.0%历史演进

10年期国债收益率是全社会**金融资产定价的锚（无风险基准利率）**。所有理财、信托、保险、股票估值，底层均以此为参照系。

```
资产预期回报率 = 无风险利率 (10年期国债收益率) + 风险溢价 (Risk Premium)
```

| 历史时期 | 10年期国债收益率中枢 | 银行保本理财预期收益率 | 寿险预定利率上限 | 社会核心投资偏好 |
| :--- | :--- | :--- | :--- | :--- |
| **2013-2017** | **3.5% - 4.5%** | 5.0% - 6.5% (刚兑) | 4.025% | 信托高息、非标理财、P2P狂热 |
| **2018-2021** | **3.0% - 3.5%** | 4.0% - 4.8% (净值化转型) | 3.5% | 优质地产信托、高收益城投债 |
| **2022-2024** | **2.3% - 2.8%** | 2.8% - 3.5% (净值波动) | 3.0% | 大额存单抢购、增额终身寿热销 |
| **2025-2026** | **1.8% - 2.2%** | 2.0% - 2.6% (波动常态化) | 2.5% / 浮动分红 | **“资产荒”爆发，锁定长钱成为共识** |

## 2. 资管新规彻底打破刚性兑付与非标资产退潮

2018年《资管新规》出台并在2022年全面落地，彻底终结了中国金融市场长达二十年的“保本保收益”影子银行时代：

- ❌ **过去**：银行理财背后打包房地产融资与地方平台非标债权，提供5%-8%隐性刚兑，投资者无需承担任何波动。
- ✅ **现在**：
  1. **净值化管理**：理财产品净值跟随底层债券市场每日涨跌，出现负收益（破净）属于正常合规现象。
  2. **非标资产清零**：高息非标资产被严禁期限错配，市场上再无“无风险高收益”的神话。

---

## 3. “资产荒”对家庭财富管理的核心冲击

“资产荒”并不是市场上没有资产，而是**兼具“本金安全、收益稳健、长期确定”的优质资产极度稀缺**。

### 居民资产配置的应对法则
1. **认清现实**：放弃对“无风险6%”的幻觉，接受低利率中枢常态。
2. **分层管理**：将资金严格拆分为“绝对保本的确定性安全资产”与“承受波动的进取增值资产”。
3. **拉长久期**：用具备终身锁息属性的年金险与分红险，提前锁定未来几十年的现金流底仓。

# 02 货币政策与低利率时代演进

## 1. 央行货币政策工具箱与传导机制

中央银行通过调控货币供给量和资金成本，实现“稳增长、稳就业、稳物价、防风险”的宏观目标。

| 工具类别 | 具体工具 | 作用机理 | 对金融市场的直接影响 |
| :--- | :--- | :--- | :--- |
| **数量型工具** | **降准 (RRR Cut)** | 降低商业银行法定存款准备金率，释放长期低成本流动性 | 增加银行可贷资金，压低银行间拆借利率（DR007/Shibor） |
| **数量型工具** | **公开市场操作 (OMO/MLF)** | 通过逆回购、中期借贷便利调节短期/中期流动性 | 维持流动性合理充裕，平抑季末/年末资金波动 |
| **价格型工具** | **7天逆回购利率 / MLF利率** | 央行核心政策利率，决定金融机构获得基础货币的成本 | 政策利率下调直接牵引市场化利率下行 |
| **传导定价** | **LPR (贷款市场报价利率)** | 商业银行根据MLF及资金成本加点报出的贷款基准 | LPR下调直接降低企业贷款利率与个人房贷利率 |

## 2. 深入理解 M1、M2 与“剪刀差”的真实经济含义

在宏观金融数据中，M1 与 M2 的增速及剪刀差是洞察实体经济活力与企业信心的最敏感体温计。

```
M0 = 流通中的现金（纸币和硬币）
M1 = M0 + 企业活期存款（狭义货币：代表即刻购买力、企业经营扩张意愿）
M2 = M1 + 居民储蓄存款 + 企业定期存款 + 其他存款（广义货币：代表全社会总流动性）

【M1-M2 剪刀差】 = M1增速 - M2增速
```

### 剪刀差状态与实体经济映射

| 剪刀差状态 | 市场现象 | 微观心理与实体经济状态 | 资产表现倾向 |
| :--- | :--- | :--- | :--- |
| **正剪刀差 (M1 > M2)** | **资金活化** | 企业把定期转为活期准备采购、扩产、发工资；居民敢消费敢买房。经济繁荣。 | 股市大涨、大宗商品牛市、消费板块领跑 |
| **负剪刀差 (M1 < M2)** | **资金定期化 / 存款沉淀** | 企业推迟投资扩产把钱存定期；居民谨慎消费拼命存钱（预防性储蓄）。实体需求不足。 | 债市走牛、年金/增额寿大卖、红利低波受追捧 |

## 3. 流动性陷阱与零利率/负利率演变

当基准利率降至极低水平时，央行无论再投放多少货币，居民和企业依然选择囤积现金或购买无风险保本资产，不再扩大借贷投资与消费。这就是凯恩斯提出的**流动性陷阱 (Liquidity Trap)**。

### 全球低利率周期的演进启示（欧美日历史）
1. **存款利率归零甚至为负**：银行对大额存款收取保管费或实际购买力在通胀/贬值中缩水。
2. **锁息工具提前抢购**：长期确定性保单与超长期国债在降息通道中成为最稀缺的“保本保收益”底仓资产。
3. **资产分化加剧**：核心优质权益资产（高股息、核心宽基）与垃圾资产两极分化。

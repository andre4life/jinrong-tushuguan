## 一、《家族信托99问》核心实务问答精粹 (Top 10)

| 序号 | 实务核心疑问 | 权威法理与实操答疑 | 核心风险防范点 |
| :---: | :--- | :--- | :--- |
| **Q1** | **家族信托设立法定门槛是多少？** | 依据中国银保监会《关于规范信托公司信托业务分类的通知》，家族信托财产金额或价值不得低于 **1000 万元人民币**（现金或等值资产，保险金信托可以总保额/现价折算）。 | 区分家庭服务信托（100万起）与家族信托（1000万起）。 |
| **Q2** | **信托财产被法院申请保全时，如何依法抗辩？** | 依据**《九民纪要》第95条**，除《信托法》第17条四种法定情形外，**法院不应准许对信托财产采取保全措施**！信托公司与委托人可直接提出执行异议。 | 确保信托设立时委托人无逾期到期债务。 |
| **Q3** | **非婚生子女能否成为家族信托受益人？** | **完全可以**！依据《民法典》第1071条，非婚生子女享有与婚生子女同等的合法权利；信托分类通知明确受益人可为委托人血亲。 | 资金来源必须合法，若用夫妻共有财产需配偶书面知情同意。 |
| **Q4** | **设立家族信托需要配偶签字吗？** | 若出资来源于**婚姻存续期间所得（夫妻共同财产）**，实务中信托公司**必须要求配偶签署《知情同意书》**，否则属于无权处分，极易被起诉撤销（参考武汉3080万案）。 | 婚前个人财产需提供完整的婚前流水确权凭证。 |
| **Q5** | **委托人破产，信托财产会被清算吗？** | **不会**！《信托法》第15条明确规定，信托财产不属于委托人的遗产或清算破产财产。 | 设立信托必须在企业健康无债务危机的“晴天”。 |
| **Q6** | **信托财产可以放哪些资产？** | 现金、大额人寿保单现金价值/身故金、标准化金融产品；股权信托与不动产信托实务中受制于过户税费，通常通过“控股公司间接持股”实现。 | 不动产直接过户目前面临契税与个税无税法豁免问题。 |
| **Q7** | **什么是信托保护人 (Protector)？** | 保护人由委托人信任的专业人士或家办委员会担任，拥有监督受托人、批准重大分配、甚至更换信托公司的权力。 | 保护人不得由委托人本人直接过度兼任以防穿透。 |
| **Q8** | **设立信托后，委托人还能随意拿回钱吗？** | **不能随意拿回**！若合同约定委托人可以随时任意全额撤回资金，境外和境内法院极易判定为“虚假信托 (Sham Trust)”并予以击穿！ | 必须通过合法的受益人信托利益分配条款合规提取。 |
| **Q9** | **保险金信托如何办理投保人变更？** | 在保险金信托 2.0 模式下，保单生效后，委托人向保险公司申请将**保单投保人与身故受益人同时变更为信托公司**，保单所有权正式确认为信托财产。 | 提前确认保险公司与信托公司的系统对接名单。 |
| **Q10** | **信托分配给子女需要交个人所得税吗？** | 中国现行税法下，信托利益分配给直系亲属受益人，暂无明确征收个人所得税的法定税目（视同直系亲属财产无偿赠与/财产分割），且中国目前**未开征遗产税与赠与税**。 | 合规保留信托合同与分配凭证，避免被错误核定。 |

# 04 家族信托与保险金信托全景架构

## 1. 《信托法》第十五条/第十六条：信托财产的独立性神话

信托（Trust）是人类财富管理史上最伟大的制度发明之一。其核心基石是：**信托财产独立于委托人、受托人以及受益人的个人财产**。

```
【信托财产独立性表现】
1. 委托人破产/负债 ──► 信托财产不属于清算破产财产，债权人不得强制执行
2. 受托人（信托公司）破产 ──► 信托财产独立，不属于信托公司破产财产
3. 受益人婚变/负债 ──► 仅能享受信托利益分配，配偶无法分割信托本金
```

## 2. 家族信托的五大核心应用场景

| 核心诉求 | 传统工具缺陷 | 家族信托解决方案 |
| :--- | :--- | :--- |
| **防挥霍败家** | 继承巨额现金后子女几年内挥霍一空、沾染不良嗜好 | **设定严密的按月给付规则，设置婚嫁、生育、深造、创业等激励条款** |
| **非婚生子女照顾** | 私生子争夺遗产引发家族丑闻，甚至导致家庭撕裂 | **信托合同完全保密，定向给付生活费，不影响家族主体传承** |
| **家族企业股权传承** | 股权分散给多个子女导致控制权丧失、夺权内耗 | **将家族控股股权装入信托，受托人持股，家族成员按信托受益份额分红** |
| **特殊需要关爱** | 家中有失能、智障或自闭症后代，父母百年后无人照料 | **指定监护人与信托定期支付康复护理金，终身闭环兜底** |

## 3. 保险金信托 1.0 / 2.0 / 3.0 全景演进

传统家族信托设立门槛通常为 **1000万元人民币**。保险金信托通过将保单的“杠杆效应”与信托的“灵活传承”结合，大幅降低了设立门槛：

```
【保险金信托 1.0】
投保人：客户 ──► 购买大额寿险/年金 ──► 指定信托公司为身故受益人 ──► 身故理赔金进入信托财产 (身故后生效)

【保险金信托 2.0】
保单投保人变更为信托公司 ──► 保单存续期内的年金、分红、退保金及身故金全部直接进入信托 (生前即可运作)

【保险金信托 3.0】
客户直接以信托资金购买保单，保单作为信托底层资产进行大类资产配置 (全生命周期定制)
```

### 案例教训：张兰离岸信托击穿案的启示
- **致命失误**：张兰虽然设立了离岸信托，但依然随意从信托账户直接给自己的私人购房汇款，保留了过度的“任意控制权”。
- **法院判决**：离岸法院认定该信托为“虚假信托 (Sham Trust)”，信托财产被债权人成功冻结追偿。
- **铁律**：**设立信托必须严格遵守受托独立性，切忌将信托当做私人钱包随意调用！**

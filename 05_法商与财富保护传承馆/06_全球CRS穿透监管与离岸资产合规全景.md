# 06 全球CRS穿透监管与离岸资产合规全景

> **导言**：CRS（Common Reporting Standard，共同申报准则）由 OECD 制定，是全球 100 多个国家和地区之间金融账户涉税信息的自动交换机制。随着“金税四期”与 CRS 大数据联网穿透，高净值客户传统的“离岸账户隐形财富”时代彻底终结，财富管理全面进入**“阳光化、合规化、制度化”**的新纪元。

## 一、CRS 运转的三大底层判定铁律

### 1.1 税收居民身份判定（Tax Residency）
- **国籍 $
eq$ 税收居民**：CRS 申报的核心依据不是你的护照国籍，而是**你在哪个国家承担无限纳税义务（税收居民身份）**。
- **中国税收居民判定标准**（新个税法）：
  1. 在中国境内有住所（因户籍、家庭、经济利益关系在境内习惯性居住）；
  2. 或无住所而在一个纳税年度内在境内居住累计满 **183 天**。

### 1.2 穿透原则（Look-Through Approach）
- 如果账户持有人是一家公司或壳架构（如 BVI、开曼、塞舌尔离岸公司）：
  - 若该公司为**消极非金融实体 (Passive NFE)**（即 50% 以上收入为股息、利息、租金、特许权使用费等被动投资收益）；
  - **金融机构必须穿透该壳架构，直接追索其背后的“实际控制人（Natural Person Controlling Person）”**，并将其个人信息报送回其实际税收居民国！

## 二、CRS 交换的核心信息与完整流程

```
【CRS 信息交换完整闭环】

 [香港/新加坡/瑞士银行/保险公司]
         │ 1. 每年对所有非居民金融账户进行穿透尽职调查 (Due Diligence)
         ▼
 [当地税务机关 (如香港税务局 IRD)]
         │ 2. 每年 9 月汇总涉税信息
         ▼
 [跨国税务自动交换网络 (AEOI Network)]
         │ 3. 自动传送给中国国家税务总局 (SAT)
         ▼
 [金税四期大数据风控平台]
         │ 4. 自动与国内个人所得税 APP、企业申报、银行流水进行交叉穿透比对！
```

### 📋 每年自动交换的核心数据字段：
1. **个人身份信息**：姓名、出生日期、国籍、中国身份证号/税号 (TIN)、常住地址；
2. **账户信息**：开户银行/金融机构名称、银行账号/保单号/信托号；
3. **财务核心数据**：
   - 截至每年 12 月 31 日的**账户年末总余额 / 净值 / 保单现金价值**；
   - 该年度内收到的**利息、股息、分红、证券变现总收益**。

## 三、家族信托与大额保单在 CRS 下的穿透规则

| 金融工具 | CRS 实体分类 | 穿透申报具体规则 | 常见误区与避坑 |
| :--- | :--- | :--- | :--- |
| **海外家族信托 (离岸信托)** | **信托通常被认定为 FI 或 Passive NFE** | • **委托人 (Settlor)**：即使是不可撤销信托，其作为设立人信息每年必定申报；<br>• **保护人 (Protector)**：若有实权，信息全额申报；<br>• **受益人 (Beneficiary)**：在固定信托中每年申报；在全权委托信托中，**一旦当年获得信托利益分配，信息与金额全额申报**。 | ❌ **误区**：“把钱放进离岸信托就可以躲避 CRS” —— **错！信托必须穿透申报全部关联人**。信托的核心功能是法律隔离与传承，而非逃税。 |
| **境外大额储蓄/分红保单** | **现金价值保单 (Cash Value Insurance)** | 保险公司作为金融机构 (FI)，每年向当地税务局申报**投保人身份信息、年末保单总现金价值（含红利累积）**；理赔或退保时申报支付金额。 | ❌ **误区**：“境外保单完全隐形” —— **错！现金价值直接计入个人离岸金融资产总额**。 |
| **境内家族信托 / 境内保单** | **境内金融资产** | **不涉及跨国 CRS 交换**。受中国境内税法管辖，合法享有保单与信托财产的法定隔离与免遗产税属性。 | ✅ **优势**：境内信托与保单结构阳光透明，配合“金税四期”合规设立，免除跨国税务双重征税风险。 |

## 💡 四、高净值客户应对 CRS 的合规金法则

1. ❌ **坚决摒弃“假身份买假护照”避税**：
   - 过去市场上利用加勒比海等小岛国“投资移民入籍”试图隐瞒中国税收居民身份的做法，已被 OECD“穿透尽调实质居住测试”全面封杀，一经查实面临巨额逃税罚金与洗钱审查。
2. ✅ **从“资产隐匿”全面转向“资产阳光化架构设计”**：
   - 承认合法纳税义务，利用税收协定（DTA）避免双重征税，利用合法免税工具（如中国税法下人寿保险身故保险金免征个人所得税）；
3. ✅ **以“境内家族信托 + 保险金信托”为财富安全核心底座**：
   - 将主要资产沉淀在主权信用最高、法律权属最稳固的境内人民币架构中，彻底规避地缘政治制裁、离岸资产冻结与全球反避税风暴。

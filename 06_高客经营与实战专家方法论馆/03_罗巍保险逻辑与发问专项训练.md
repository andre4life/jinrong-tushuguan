# 03 罗巍保险逻辑与发问专项训练

## 1. 罗氏“启发式发问”技术核心逻辑

罗巍老师的核心教学主张：**“永远不要试图说服客户，所有的推销都会遭遇本能的抵抗；你要做的是用精准的问题，让客户自己说服自己。”**

```
【发问三段论】
现状发问 (事实探寻) ──► 痛点推演 (后果放大) ──► 方案呈现 (水到渠成)
```

## 2. 财富“四权分离”经典发问模型

罗巍老师提出，绝大多数人只关注财产的“数量”，却忽视了财产在法律上的**“四权属性”**：

| 权利属性 | 核心发问话术 | 揭示的法律本质 |
| :--- | :--- | :--- |
| **1. 归属权 (所有权)** | “王总，这笔钱现在写在您的账上，如果企业万一遇到经营纠纷，在法律上它到底百分之百属于谁？” | 明确财产归属，识别家企混同与代持风险 |
| **2. 控制权** | “如果把钱直接过户给孩子，孩子一旦冲动创业或婚变，您还能说了算吗？” | 揭示过早赠与丧失控制权的巨大风险 |
| **3. 收益权** | “如何保证这笔钱无论市场利率降到多低，每年都能稳稳当当给您打钱？” | 锁定长期终身确定收益 |
| **4. 传承权** | “百年之后，这笔钱能否按照您的绝对意愿，一分不差、没有争议地交给您最疼爱的人？” | 规避法定继承纷争与繁琐公证 |

## 3. 实战发问演练示范

> **顾问**：“张总，如果有一项金融契约，能让您在企业顺风顺水的时候把一部分合法利润悄悄锁住；万一未来大环境不好，这笔钱不受公司任何债务追偿，每年雷打不动给您和太太打30万养老金，活到100岁领到100岁；将来百年之后，还能保密、免纠纷地传给孩子。您会愿意花10分钟了解一下这个法律架构吗？”

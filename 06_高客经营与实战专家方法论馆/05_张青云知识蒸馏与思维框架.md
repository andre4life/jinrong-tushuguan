# 05 张青云知识蒸馏与思维框架

## 1. 张青云财富管理营销认知底层模型

张青云老师将寿险营销从传统的“人情推销”升维至**“认知驱动型财富咨询”**：

```
【认知四层跃迁】
L1. 产品推销层：比条款、比收益、比佣金（最低维内卷）
L2. 需求满足层：按客户提出的表面需求找产品
L3. 方案设计层：运用标普象限、四账户模型为家庭量身定制
L4. 顶层架构层：融合民法典、税法、信托法与公司法，为高客搭建家族基业长青防火墙（最高维降维打击）
```

---

## 2. 展业赋能的核心转化原则
1. **说人话**：把高深晦涩的法律条文和精算概念，翻译成客户一听就懂的大白话和生活比喻。
2. **抓本质**：不谈虚无缥缈的概念，直击客户对“安全性、控制权、确定现金流”的深层焦虑。
3. **建信任**：以三师共诊（理财师 + 律师 + 税务师）的专业智库团队形象赋能展业，彻底摆脱单兵作战困局。

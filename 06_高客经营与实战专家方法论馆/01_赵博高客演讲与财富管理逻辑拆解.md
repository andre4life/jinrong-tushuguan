# 01 赵博高客演讲与财富管理逻辑拆解

## 1. 高净值客户（高客）的核心心理画像与底层痛点

资深财富管理专家赵博在面向超高净值企业主的千场演讲中深刻总结：**“高客最大的恐惧不是少赚100万，而是辛辛苦苦打拼几十年积累的几个亿，在一夜之间因为政策、债务、婚变或传承风险化为乌有。”**

| 客户阶层 | 资产规模 | 核心关切点 | 沟通叙事重点 |
| :--- | :--- | :--- | :--- |
| **大众客户** | < 100万 | 收益率多少？什么时候能回本？ | 产品收益、性价比、日常储蓄 |
| **中产精英** | 100万 - 1000万 | 养老够不够？子女教育与抗通胀 | 资产配置、确定现金流、四账户闭环 |
| **高净值客户 (HNW)** | 1000万 - 1亿 | 怎么保证本金绝对安全？怎么做家企隔离？ | 法律防火墙、三师共诊、确定性资产池 |
| **超高净值 (UHNW)** | > 1亿 | 家族企业怎么平稳传承？怎么防子女败家？ | 家族办公室、家族信托、离岸合规、家风治理 |

---

## 2. 赵博演讲经典四步叙事结构模型

```
1. 【宏观降维】—— 剖析百年未有之大变局、低利率时代与金税四期，打破客户过去的认知舒适区
      ▼
2. 【痛点唤醒】—— 用真实的标杆企业家暴雷判例（婚变、债务、传承争议），引发客户深度自我审视
      ▼
3. 【逻辑升维】—— 提出“资产负债表防御 + 确定性资产底仓 + 法律架构”的系统化财富顶层设计
      ▼
4. 【工具落地】—— 自然引出大额年金、分红险、家族信托等法律与金融工具，完成闭环
```

### 金句摘录
- **“创富靠能力和运气，守富靠法律和制度，传富靠智慧和工具。”**
- **“钱装在兜里是钱，装在公司是风险，装在法律架构里才是真正的家族基业。”**

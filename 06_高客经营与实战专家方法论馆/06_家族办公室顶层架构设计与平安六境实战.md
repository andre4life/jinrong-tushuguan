3. **第三步：出具《家族财富全景保护与传承规划报告书》**：
   - 为高净值客户呈现视觉化逻辑图（深蓝+橙色高品质版），清晰展示风险现状与破局方案；
4. **第四步：高客私享陪谈与信托/保单签约落地**。

## 💡 三、保险金信托 1.0 ➔ 4.0 升级演进与高客切入点

```
【保险金信托四大演进形态】

  • 1.0 模式：【保单生效后入信托】—— 投保人自留保单，仅将【身故保险金受益人】指定为信托公司。
  • 2.0 模式：【保单权利完全入信托】—— 【投保人 + 受益人】双变更为信托公司，彻底剥离委托人债务。
  • 3.0 模式：【信托资金直接投保】—— 委托人先设立信托并注入资金，由【信托公司作为投保人】为被保人购买保单。
  • 4.0 模式：【多委托人/混合资产信托】—— 融合保单、现金、股权、不动产为一体的综合性全景家族信托。
```

> **高客沟通金句**：
> *“信托解决的是【财富传给谁、怎么传、分多少】的精准控制权；而保险解决的是【用极高的确定性与复利杠杆，把几百万放大为几千万信托现金池】。保险是信托最好的放大器，信托是保险最强大的遥控器！”*

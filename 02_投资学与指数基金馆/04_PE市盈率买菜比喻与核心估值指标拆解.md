# 04 PE市盈率买菜比喻与核心估值指标拆解

## 1. 核心金融估值概念的“买菜与菜摊”通俗大白话比喻

很多初学者觉得市盈率、市净率、股息率枯燥难懂。其实用**菜市场买菜摊**的生活常识，一眼就能看透底层逻辑：

| 估值指标 | 专业金融学定义 | 🥬 菜市场买菜摊的大白话比喻 | 怎么看好坏？ |
| :--- | :--- | :--- | :--- |
| **PE (市盈率)**<br>`Price / EPS` | 股票价格 / 每股收益<br>(总市值 / 净利润) | **【买菜摊的回本年限】**<br>隔壁王大爷的菜摊每年能净赚 **10万元**。如果王大爷开价 **100万元** 把摊位卖给你，**PE = 10倍**（意味着你买下来需要10年靠赚的利润回本）。如果他开价 **500万元**，**PE = 50倍**（你需要50年才能回本！）。 | **越低通常越便宜**；但要排除夕阳行业陷阱。 |
| **PB (市净率)**<br>`Price / Book Value` | 股票价格 / 每股净资产<br>(总市值 / 净资产) | **【菜摊物理资产的打折度】**<br>王大爷菜摊里的冷柜、电子秤、遮阳棚等二手卖掉值 **10万元**。如果他把整个菜摊作价 **8万元** 卖你，**PB = 0.8倍**（破净，相当于打了8折买资产）；若作价 **30万元**，**PB = 3倍**。 | 重资产行业（银行、基建）看PB；轻资产科技看PE。 |
| **股息率 (Dividend Yield)**<br>`DPS / Price` | 每股现金分红 / 股票价格 | **【每年拿到手的现金分红】**<br>你花 **100万元** 买了菜摊，王大爷约定每年年底真金白银给你塞 **5万元** 现金红包，**股息率 = 5%**。不管菜摊以后能卖多少钱，这5万现金是实打实进你兜里的。 | **股息率 > 国债利率** 时，具备极高安全边际。 |
| **ROE (净资产收益率)**<br>`Net Income / Equity` | 净利润 / 净资产 | **【做生意的本领与赚钱效率】**<br>王大爷投入 **10万元** 本钱，一年能净赚 **2万元**，**ROE = 20%**。如果李大妈投入 **10万元** 本钱一年只赚 **2000元**，**ROE = 2%**。巴菲特最看重此指标。 | **ROE > 15%** 是优秀长牛企业的核心标志。 |

## 2. 估值的三维判定体系：如何精准识别市场高低点？

判断一个指数（如沪深300或标普500）当前是贵还是便宜，不能只看点位绝对值（比如4000点不一定比3000点贵），而要看**估值分位数与股债利差**：

### 维度一：PE 历史分位数 (Percentile)
- **极度低估（贪婪买入区）**：历史 PE 分位数 < 20%（比如沪深300 PE < 11倍）。全市场极度悲观，筹码极其便宜。
- **合理估值（正常定投区）**：历史 PE 分位数在 20% - 70% 之间（PE 在 11 - 14倍）。
- **极度高估（分批止盈区）**：历史 PE 分位数 > 80%（PE > 16倍）。全民狂热，买菜摊需要几十年回本，果断分批卖出。

### 维度二：格雷厄姆股债利差模型 (Equity Risk Premium)
```
股债利差 = 股票收益率 (1 / PE) - 10年期国债收益率
```
- 含义：将股票的盈利回报与“躺赚的国债收益”进行性价比对比。
- **利差 > 4%**：股票比国债划算得多，是历史大底区域（如2018年底、2024年初）。
- **利差 < 1%**：股票极度昂贵，性价比远不如国债，应大举撤退转入年金/国债。

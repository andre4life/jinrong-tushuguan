# 03 沪深300指数20年历史复盘与定投实证

## 1. 沪深300指数简介与地位

沪深300指数（000300.SH / 399300.SZ）由沪深两市中市值规模最大、流动性最好的300家最具代表性的A股龙头上市公司组成，覆盖了A股总市值的约60%，是衡量中国核心资产走势的最核心晴雨表。

### 20年长期年化复合收益率 (CAGR)
- **单笔一次性买入（2004年末1000点买入并持有至今约4000点）**：复合年化收益率约为 **7.2%**（若计入现金分红全收益指数约 **8.8%**）。
- **年化波动率**：高达 **25%-30%**（显著高于美股的15%-18%）。

## 3. A股“高波动、牛短熊长”特征与定投“微笑曲线”

A股的特点是**“牛市急促暴烈，熊市漫长震荡”**。这种特征对“一次性单笔重仓”极其残酷（如果买在2007年5800点或2015年5300点高位，需要承受漫长的回撤痛苦），但**对“机械化定期定额投资”（定投）却是天然的沃土**。

```
点位
 │
5000│  ● 开始定投（少买份额）
4000│    ╲
3000│      ╲                                  ● 获利止盈（收益爆发！）
2000│        ●───────●───────●───────●───────╱
1000│         熊市底部持续定投（大量收集廉价筹码）
 0  └────────────────────────────────────────────────► 时间
```

### 微笑曲线实证数据对比
- **定投平均成本公式**：由于低位买入的份额多、高位买入的份额少，定投的持仓加权平均成本远低于市场点位平均值。
- **实证结果**：在沪深300从5000点跌至3000点再反弹至4000点的过程中，单笔投资者依然亏损20%，而坚持定投的投资者早已实现 **15%-25% 的正收益**。

---

## 4. 沪深300核心定投原则
1. **低估多投，高估少投/止盈**：结合 PE 估值百分位（PE < 11倍加大扣款，PE > 15倍分批止盈）。
2. **设定目标止盈率（如25%-30%）**：达到目标后分批赎回转入安全稳健账户（年金险/固收），锁定利润。
3. **资金必须是3-5年不用的闲钱**：切勿用短期生活费定投。

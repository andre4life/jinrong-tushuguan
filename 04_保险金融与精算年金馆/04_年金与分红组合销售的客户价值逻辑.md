# 04 年金与分红组合销售的客户价值逻辑

## 1. 为什么“单打独斗”不如“组合拳”？

在为客户设计财富方案时，单一配置传统年金或单一配置分红险往往存在各自的痛点：
- **纯传统年金**：确定性100%，但若未来发生恶性通胀或高息周期，缺乏向上弹性。
- **纯分红保险**：向上弹性好，但保守型客户对浮动部分心存顾虑，希望底线更高。

```
【终极解法：组合销售 (Portfolio Strategy)】
【传统年金 (锁死底线)】 + 【分红险 (博取弹性)】 = “守正出奇、攻守兼备”
```

---

## 2. 组合销售对客户的四大核心价值

| 价值维度 | 客户痛点 | 组合方案解决方案 |
| :--- | :--- | :--- |
| **1. 确定与弹性平衡** | 既想要绝对安全，又不想错失未来增长红利 | **年金提供刚性下限（覆盖刚需），分红提供浮动上限（抵御通胀）** |
| **2. 现金流梯队化** | 人生不同阶段的开销是不均匀的 | **短期利用分红增额累积，中长期利用年金固定领取，节奏完美呼应** |
| **3. 跨越经济周期** | 担心长达30-50年的利率周期反复变化 | **低利率时年金锁息保底，高利率时分红险分享险企超额投资回报** |
| **4. 心理舒适度最高** | 既不因全保底觉得收益平淡，也不因全浮动感到焦虑 | **给客户最舒服的投资心智模型：保底够用，多了是惊喜** |

---

## 3. 三大典型客户方案组合模型

### 方案A：中产家庭养老储备（60% 年金 + 40% 分红）
- 60%资金锁定终身刚性年金（确保退休后每月基本温饱一分不少）。
- 40%资金投入高分红产品（博取长期分红，用于晚年旅游、品质康养与医疗护理）。

### 方案B：少儿教育与婚嫁传承（50% 年金 + 50% 增额分红）
- 18-22岁大学阶段固定领取年金作为教育金。
- 30岁婚嫁及创业阶段按需减保或利用累积红利作为成家启动资金。

### 方案C：企业主家企隔离与长周期蓄水池（30% 年金 + 70% 分红）
- 大额分红保单沉淀企业经营利润，筑牢家企防火墙，同时享受长期资产增值。

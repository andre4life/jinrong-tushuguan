## 一、《大额保单配置必修的十一堂课》核心精华拆解

| 序号 | 核心课堂主题 | 核心法商原理与工具 | 经典高客实战案例 |
| :---: | :--- | :--- | :--- |
| **第1课** | **人寿保险与大额保单概述** | 《保险法》第23条（不得查封人身险特定款项）、第39条（投保人与被保人指定受益人权利）。 | 区分主险与附加险、现金价值与身故保额的权属归属。 |
| **第2课** | **婚姻财富保障** | 依据《民法典》第1063条，父母作为投保人为子女购买保单并指定子女为身故受益人，属于**子女个人财产，离婚女婿无权分割**。 | 2000 万嫁妆通过大额年金保单实现婚变绝对隔离。 |
| **第3课** | **子女财富支持** | 设定年金领取年龄与分期频率，替代一次性大额转账给子女，防止子女过早掌管巨款丧失奋斗动力。 | 设立“名校留学奖学金”与“婚后按月生活补助”。 |
| **第4课** | **晚年财富规划** | 解决“老龄化、长寿风险、失去行为能力照护”痛点，保单现金流与平安高端康养（臻颐年/颐年城）保证入住权绑定。 | 退休后每年保证领取 100 万元直到终身。 |
| **第5课** | **债务隔离与实操误区** | ❌ **误区**：“只要买了保单就绝对不还债” —— **错！**必须在无债务纠纷时购买，且保单现金价值在投保人涉诉时可能面临执行；<br>✅ **破局**：通过**保险金信托 2.0（变更投保人为信托公司）**实现绝对隔离。 | 企业主 4000 万银行贷款连带担保下的合规家企隔离案。 |
| **第6课** | **现金流管理与质押贷款** | 大额保单现金价值可向保险公司申请最高 **80% 质押贷款**，几分钟极速到账，利率低且不影响保单底层复利增值与分红！ | 企业紧急周转时调动 800 万现金，渡过难关后还款。 |
| **第7课** | **家族企业代际传承** | 家族实业股权由长子全额继承，大额人寿保单身故金指定给二女儿与小儿子，实现**“动静平衡、手心手背都是肉”的公平无争端补偿**。 | 8000 万不动产与 4000 万保单对冲化解遗产争端。 |
| **第8课** | **与家族信托无缝对接** | 保险金信托 1.0 ➔ 4.0 模式，利用保单高杠杆把 1000 万放大为 3000 万信托现金流池。 | 千万级信托门槛通过保险金信托低门槛撬动。 |
| **第9课** | **家庭财富税务优化** | 中国税法下人寿保险身故理赔金**免征个人所得税**；且目前中国未开征遗产税。 | 大额财富代际流转 0 损耗合规完税传承。 |
| **第10课**| **CRS金融账户监管** | 境内人民币大额保单属于境内金融资产，不涉及跨国 CRS 涉税信息交换，主权信用最稳固。 | 外贸企业主海外资产合规回流配置境内大额保单。 |
| **第11课**| **综合管理与全流程闭环** | 结合“三师共诊”（理财师+法商律师+税务师），出具《家族全景大额保单配置报告》。 | 单笔千万级保单签单标准作业流程 SOP。 |

# 05 医养结合生态与高品质养老服务权益

## 1. 中国“9073”养老格局与家庭养老困局

国家卫健委权威数据定义了中国老龄化社会的基本格局：
- **90% 居家养老**：绝大多数老人在自己家中养老，但面临“保姆难找、紧急就医难、适老化改造缺乏、孤独无护”等痛点。
- **7% 社区养老**：依托社区日间照料中心。
- **3% 机构养老**：入住高品质专业养老机构（存在排队难、床位紧缺、门槛高等壁垒）。

## 2. 平安“保险 + 服务”大医疗大康养全景生态矩阵

平安集团通过“综合金融 + 医疗健康”双轮驱动，构建了行业最具竞争力的“富国裕民”养老权益生态：

```
【金融层】终身确定现金流 + 分红资产增值
    │
    ▼
【服务层】专属医养健康服务权益矩阵
 ├─ 居家养老体系：1个智能管家 + 1个就医管家 + 1个生活管家 (居家V1/V2)
 ├─ 高端旗舰康养：逸享城 / 颐年城高端社区入住优先权
 └─ 顶尖医疗绿通：名医门诊预约 / 住院加速 / 私董保健医
```

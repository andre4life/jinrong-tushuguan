# 02 金融高频公式与速查手册

## 1. 核心投资与收益类公式速查

| 公式名称 | 数学表达式 | 中文释义与参数说明 | Excel / 实操计算方法 |
| :--- | :--- | :--- | :--- |
| **内部收益率 (IRR)** | $\sum_{t=0}^n \frac{C_t}{(1 + IRR)^t} = 0$ | 使未来所有净现金流现值之和等于零的折现率（真实复利） | \`=IRR(values)\` 或考虑日期的 \`=XIRR(values, dates)\` |
| **净现值 (NPV)** | $NPV = \sum_{t=0}^n \frac{C_t}{(1 + r)^t}$ | 将未来所有现金流入流出按折现率 $r$ 折算到当下的净价值 | \`=NPV(rate, value1, value2...)\` |
| **复合年均增长率 (CAGR)** | $CAGR = \left(\frac{V_{\text{end}}}{V_{\text{begin}}}\right)^{\frac{1}{n}} - 1$ | 投资在 $n$ 年间几何平均的每年复合增长率 | \`=(Vend/Vbegin)^(1/n) - 1\` |
| **72法则 (Rule of 72)** | $\text{翻倍年数} \approx \frac{72}{\text{年化复利率 (\%)}}$ | 口算本金在固定复利率下翻一番所需的近似年数 | 例：年化 3% 复利，约需 $72 / 3 = 24$ 年翻倍 |
| **夏普比率 (Sharpe Ratio)** | $S = \frac{E(R_p) - R_f}{\sigma_p}$ | 组合预期超额收益除以组合标准差（波动风险） | 超额收益 / 波动率，衡量性价比 |

## 2. 宏观与估值核心公式

- **市盈率 (PE)**：$PE = \frac{\text{股价 } P}{\text{每股收益 } EPS} = \frac{\text{总市值}}{\text{净利润}}$
- **市净率 (PB)**：$PB = \frac{\text{股价 } P}{\text{每股净资产 } BVPS} = \frac{\text{总市值}}{\text{净资产}}$
- **格雷厄姆股债利差**：$\text{Equity Risk Premium} = \frac{1}{PE} - \text{10年期国债收益率}$
- **实际利率费雪方程式**：$r_{\text{实际}} \approx r_{\text{名义}} - i_{\text{通胀率}}$

## 3. 保险精算与传承测算公式

- **分红实现率**：$\text{实现率} = \frac{\text{实际派发红利总额}}{\text{计划书演示红利总额}} \times 100\%$
- **退休金缺口**：$\text{总缺口} = \text{期望年开销} \times (1+g)^N \times T - (\text{预期社保养老金总和})$

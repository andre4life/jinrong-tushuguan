# 03 金融陷阱识别与理财防坑指南

## 1. 庞氏骗局（Ponzi Scheme）识别模型

任何金融骗局无论包装成“区块链、高新农业、元宇宙、原始股还是碳中和”，其底层数学模型均符合庞氏特征：

```
【庞氏骗局三大致命死穴】
1. 承诺远超常识的“保本无风险超高收益”（如年化 12%-36%，按月按日付息）
2. 缺乏真实的底层生产力资产与盈利造血能力（钱进去了没有实际经营闭环）
3. 靠拉人头发展下线拿提成，用后来人的本金填前面人的利息（一旦新韭菜枯竭瞬间崩盘）
```

## 3. 终身理财避坑五大黄金铁律
1. **看牌照**：资金只流向持有中国央行、国家金融监管总局、证监会正规金融牌照的机构。
2. **懂逻辑**：看不懂底层怎么赚钱的产品，一个字都不要碰。
3. **查流水**：转账绝不转入任何个人账户或非金融机构公户。
4. **守底仓**：无论如何，家庭必须保留一块雷打不动的“确定性安全资产”。
5. **信常识**：天下没有免费的午餐，高收益必然伴随着高风险。

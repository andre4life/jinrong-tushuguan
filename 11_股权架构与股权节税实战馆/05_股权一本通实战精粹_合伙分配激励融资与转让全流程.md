## 一、合伙人股权分配“四张关键评估表”

| 评估维度 | 核心考量指标 | 权重与分配标准 | 避坑铁律 |
| :--- | :--- | :--- | :--- |
| **1. 岗位价值表** | 战略规划、日常决策、团队带队、法律责任承担。 | 占总分配的 **40% - 50%**，创始人必须独占最高权重。 | 谁承担公司法人与对外兜底责任，谁拿大头。 |
| **2. 资金出资表** | 真金白银实缴到账金额。 | 占总分配的 **20% - 30%**。 | 警惕“光出钱不干活的财务投资人”拿走过半股份抢夺控制权。 |
| **3. 核心能力表** | 独家专利技术、不可替代的产品研发实力。 | 占总分配的 **15% - 20%**。 | 技术折股必须绑定服务年限，不得一次性全额发放。 |
| **4. 资源贡献表** | 客户渠道、牌照资质、政府产业资源。 | 占总分配的 **10% - 15%**。 | **严禁给纯“拉皮条/资源型合伙人”大股份**！资源往往是一次性的，应采用佣金提成或顾问费替代股权。 |

## 二、股权融资与资本对赌防翻车“四大核心条款”

1. **领售权 (Drag-Along Right / 拖拽权)**：
   - 投资人找到第三方收购公司时，有权强制创始人以同样价格一起卖掉公司。**创始人必须在条款中增加：收购估值必须达到约定倍数以上，且创始人拥有一票否决权！**
2. **随售权 (Tag-Along Right / 共同出售权)**：
   - 创始人想卖股权套现跑路时，投资人有权按同等条件一起出售股份。保障小股东不被大股东单独抛弃。
3. **反稀释条款 (Anti-Dilution Protection)**：
   - 避免后续低估值降价融资导致早期投资人股份被严重稀释。实务中应采用“加权平均法 (Weighted Average)”，坚决拒绝“完全棘轮法 (Full Ratchet)”！
4. **优先清算权 (Liquidation Preference)**：
   - 公司破产清算时，投资人有权先于普通股股东收回本金及约定利息（如 1x 本金 + 8% 年利）。
